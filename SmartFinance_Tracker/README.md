# Умный трекер личных финансов (SmartFinance Tracker)

**Роль в проекте:** Системный аналитик
**Статус:** MVP (Минимально жизнеспособный продукт)

## О проекте
SmartFinance Tracker — это система для централизованного учета мультивалютных активов пользователя, анализа структуры расходов и автоматической переоценки баланса по актуальным обменным курсам.

## Границы системы (Scope)
**Входит в MVP:**
- Создание и управление мультивалютными счетами.
- Учет доходов, расходов и переводов.
- Интеграция с внешним REST API для получения курсов валют.
- Расчет общего баланса в базовой валюте пользователя.

**Не входит в MVP:**
- Интеграция с банками и распознавание чеков.
