# Сценарии использования (Use Cases)

В этом документе описаны подробные пошаговые сценарии взаимодействия пользователя с системой SmartFinance Tracker.

## UC-1: Добавление транзакции (расхода)
**Участники:** Пользователь, Система
**Предусловие:** Пользователь авторизован и у него создан хотя бы один счет.

**Основной сценарий (Успешный путь):**
1. Пользователь нажимает кнопку «Добавить расход».
2. Система открывает форму с полями: Сумма, Валюта, Счет списания, Категория, Дата, Комментарий.
3. Пользователь заполняет обязательные поля (Сумма, Счет, Категория) и нажимает «Сохранить».
4. Система проверяет правильность заполнения полей (например, сумма должна быть больше нуля).
5. Система сохраняет транзакцию в базу данных.
6. Система пересчитывает баланс выбранного счета (вычитает сумму расхода).
7. Система закрывает форму и показывает обновленный баланс.

**Альтернативный сценарий:**
* *4а. Ошибка заполнения:* Если пользователь забыл выбрать категорию, Система подсвечивает поле красным текстом "Выберите категорию" и прерывает сохранение до исправления ошибки.

## UC-2: Перевод между своими валютными счетами
**Участники:** Пользователь, Система
**Предусловие:** Пользователь авторизован и имеет счета в USD и RUB.

**Основной сценарий:**
1. Пользователь открывает форму перевода.
2. Выбирает счет списания (USD) и счет зачисления (RUB), вводит сумму списания.
3. Система запрашивает актуальный курс кросс-конвертации из своей базы данных.
4. Система показывает пользователю расчетную сумму зачисления (сколько придет в RUB).
5. Пользователь подтверждает перевод.
6. Система списывает USD, зачисляет RUB по курсу и обновляет балансы обоих счетов в рамках одной транзакции.

## UC-3: Просмотр сводного баланса (с фоновым получением курсов)
**Участники:** Пользователь, Система, Внешний API курсов валют
**Предусловие:** У пользователя есть несколько счетов в разных валютах. Базовая валюта профиля — рубли (RUB).

**Основной сценарий:**
1. Пользователь открывает главный экран трекера.
2. Система запрашивает из БД текущие остатки по всем счетам.
3. Система находит в БД свежий курс валют на сегодняшний день.
4. Система пересчитывает валютные счета в базовую валюту (RUB) по этому курсу.
5. Система суммирует все полученные остатки.
6. Система показывает на экране виджет: «Общий баланс: X ₽».

**Альтернативные сценарии (Отказоустойчивость):**
* *3а. Свежего курса в БД нет:* Система делает запрос к Внешнему API. API отвечает успешно. Система сохраняет свежий курс в БД и переходит к шагу 4.
* *3б. Внешний API недоступен:* Если Внешний API не отвечает более 5 секунд (таймаут), Система отменяет запрос, берет из БД последний известный (например, вчерашний) курс, делает пересчет по нему и выводит баланс с предупреждением: «Данные рассчитаны по курсу на вчерашний день».
