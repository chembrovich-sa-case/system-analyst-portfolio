# 02. Сценарии использования (Use Cases)

## UC-1: Создание заявки в Service Desk

* **Акторы:** Заявитель (Сотрудник).
* **Предусловия:** Пользователь авторизован в системе.
* **Постусловия:** Заявка сохранена в базе данных со статусом `Новая`, создано уведомление для Диспетчера.

### Основной успешный сценарий (Main Flow):
1. Пользователь переходит на форму «Создать заявку».
2. Система отображает форму с полями: *Тема*, *Категория*, *Описание*, *Срочность*, *Вложения*.
3. Пользователь заполняет обязательные поля (*Тема*, *Категория*, *Описание*, *Срочность*) и нажимает «Отправить».
4. Система проверяет корректность заполнения полей (валидация).
5. Система генерирует уникальный номер заявки (ID), присваивает статус `Новая`, фиксирует время создания.
6. Система отправляет уведомление Диспетчеру первой линии.
7. Система перенаправляет пользователя на страницу созданной заявки с сообщением об успехе.

### Альтернативные сценарии (Alternative Flows):
* **4a. Не заполнено обязательное поле:**
  1. Система подсвечивает не задействованные поля красным цветом.
  2. Выводится сообщение: *"Заполните обязательное поле [Название поля]"*.
  3. Заявка не сохраняется, система ожидает действия пользователя.

* **4b. Размер прикрепленного файла превышает 10 МБ:**
  1. Система выводит ошибку: *"Максимальный размер файла — 10 МБ"*.
  2. Файл не загружается.
